# `app/swarm/` Agent Instructions (Engine Adapter & Upstream Swarm Simulator Core)

This directory contains the pinned GPL-3.0 Swarm Simulator economy and the Roach Colony adapter that wraps it.

## Critical Rules

1. **Never modify `app/swarm/source/` or `app/swarm/vendor/`**:
   - `app/swarm/source/` is pinned at upstream commit `06b4f404aa324a0b454348508cfa63d5c0f1ff54`.
   - All Roach Colony behavior, caching optimizations, active-time balance (`applyActiveBalance`), Dormant Opening, and snapshot projections belong in `app/swarm/adapter.js`.
2. **Never hand-edit generated files**:
   - `app/swarm/core.generated.js`, `app/swarm/data.generated.json`, and `app/engine.js` are generated by `npm run build` (`scripts/build/build-engine.cjs`).
   - Always run `npm run build` after editing `app/swarm/adapter.js`.

## Performance & Cache Invariants in `app/swarm/adapter.js`

The upstream CoffeeScript engine was written for a desktop browser where recomputing all 58 units' `Decimal` producer-path polynomials on every click went unnoticed. On the LG TV's Chromium 68 CPU, you must preserve these adapter-level invariants:

- **Split Cache Invalidation (`cache.onUpdate` vs `cache.invalidateStats`)**:
  - `cache.onUpdate()` clears only count-dependent caches (`unitCount`, `unitRawCount`, `unitMaxCostMet`, `upgradeMaxCostMet`, `upgradeIsUpgradable`, `velocity`, `totalProduction`, `producerPathCoefficients`, `_upgradeLevels`) while keeping `stats`, `eachCost`, `eachProduction`, and `_capCache` warm.
  - `cache.invalidateStats()` clears `stats`, `eachCost`, `eachProduction`, `_capCache`, and `_ascendCost` and is called only when an upgrade count changes (`Upgrade._setCount` / `_addCount`), a stat-bearing unit (`mutagen`, `ascension`, `invisiblehatchery`) changes, or the nest wakes.
- **Zero-Floor `ProducerPath.coefficient` Short-Circuit**:
  - Upstream `ProducerPath.prototype.coefficient` calls `prodEach()` for every link in the chain before multiplying by `parent.count().floor()`. Short-circuiting when `floorCount.isZero()` avoids evaluating 200+ unused late-tier producer paths on every tick.
- **`Unit._getCap` Sentinel Caching**:
  - 57 of 58 units have no capacity limit (`_getCapRaw()` returns `undefined`). Upstream CoffeeScript checked `if cache[name] != null`, which treated `undefined` as a cache miss on every `unit.count()` call and recomputed `this.stats()`. Store `false` in `_capCache` for uncapped units.
- **Non-Reifying Routine Saves & Fast Forage**:
  - `Game.prototype.exportState` serializes `live.unittypes` with current tick `unit.count()` values directly without calling `game.reify()` or `JSON.parse(JSON.stringify(...))`.
  - `Game.prototype.act('forage')` updates `meat` (and `larva` on dormant even forages) in `session.state.unittypes`, `unitRawCount`, `unitCount`, and `producerPathCoefficients` in place without calling `game.reify()`.
- **Snapshot Vocabulary Contract**:
  - `Game.prototype.snapshot` returns source vocabulary (`meat`, `larva`, `drone`, `queen`, etc.) in `nextGoal` and `hint.text`, which `tests/swarm-engine.cjs` asserts directly and `RoachTheme.text()` translates at the UI boundary (`tests/theme.cjs`). Keep `adapter.js` independent of `app/theme.js`.
